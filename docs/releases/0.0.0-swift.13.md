The `EmbedPDF`, `EmbedPDFModels` and `EmbedPDFUI` libraries, rebuilt with Rust 1.100.1 and otherwise unchanged from 0.0.0-swift.12 (upstream `cda9e82a4`, viewer 3.4.0). This tag is the commit the release train makes to pin the repository-root `Package.swift` and `platforms/apple/EmbedPDF/Package.swift` to `apple-engine-fa855fc030c10b9f`, the engine it builds in the same run, replacing `apple-engine-44a23eb0573339c7`, which 0.0.0-swift.12 pinned. No local package path or engine environment flag is required.

SwiftPM: `.package(url: "https://github.com/MFB-Technologies-Inc/embed-pdf-viewer", exact: "0.0.0-swift.13")`

The runtime fork is still `9472117ed`. The toolchain moved from Rust 1.100.0 to 1.100.1 ([`104cf9fe6`](https://github.com/MFB-Technologies-Inc/embed-pdf-viewer/commit/104cf9fe6)), and `rust-toolchain.toml` is an input of the engine hash, so the train builds a new engine. There are no Rust source changes.

## Breaking changes from 0.0.0-swift.12

None. The Swift API is the same.
