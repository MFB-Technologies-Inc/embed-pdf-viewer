# Release notes

The release train (`.github/workflows/release-train.yml`) reads each release's notes from this directory, so they are written and committed before you dispatch it. The Swift package's notes are `<swift_version>.md` (for example `0.0.0-swift.8.md`) and the Rust viewer bundle's are `rust-viewer-<viewer_version>.md`, each named for its tag. The C# engine's tag names the pin commit, which does not exist until the train makes it, so its notes are a single `dotnet-engine.md` that every C# release reuses: edit it in place when that release changes. The train's preflight job stops the train before anything is published if one of the three files is missing.
